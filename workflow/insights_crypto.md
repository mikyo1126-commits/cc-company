# 週次レビューからの改善方針（仮想通貨ネタの期間用）

週次分析の改善方針のうち、仮想通貨ネタにしても良い影響しかない「構成・書き方」だけを抜き出したもの。
テーマ候補・扱う市場・FX特有の方針は含めない（題材は必ず仮想通貨にする）。

元にした分析: 2026-11-09〜11-15（11/16〜11/22 向け）

## 今週の改善方針

1. **最後の一文まで、日本語として完結させる。** 先週は途中で終わった文（「〜と割り切って」「〜決めてあるから」）が夜の下位2本になった。出す前に最後の文を読み、「〜する」「〜した」「〜しない」などの述語で終わっているかを確かめる。長すぎる時は最後を削らず、真ん中の説明を1つ減らす。

2. **言い方の決まりと基本の言葉を、出す前に確かめる。**
   - 「本番」は「本トレード」、「減る額」は「損失額」か「負け額」、「何円減るか」は「いくら損失になるのか」、「見たか」は「確認したか」にする。チェックリストの項目でも同じ。
   - 成行・指値・ロット・損切り・利確・ロスカット・スプレッド・含み益・エントリーは、そのまま書く。言い換えない。
   - それ以外の専門用語は、普段の言葉にする。例：「FRB」は「アメリカの中央銀行」、「利上げ観測」は「金利を上げるという見方」。

3. **夜の失敗談は、1行目を必ず「以前の僕がやった失敗談」にする。** 2行目が実質の1行目になるので、2行目を24文字以内で「何をして、どうなったか」の一文にする。数字は使わない。締めはいろいろな形にする（「今は〜」で締めるのは週2本まで）。同じ絵文字を同じ場所に置くのも続けない。

4. **テーマ（扱う失敗や現象）は週1回まで。** 直近の自動投稿と同じ失敗・同じ切り口は使わない。

5. **平日の朝は、チェックリストで締めるのを基本にする。** 4週間の累計では、チェックリストつきの方がエンゲージ率もブックマークも上回っている。項目は2〜3つ。項目でも方針2の言い方を守る。前置きは毎回違う言い方にする。

6. **週末は、同じ材料を2回使わない。**
   - 土曜夜と日曜朝は、土曜朝の中心にした話とは別の通貨・別の理由を選ぶ。
   - 日曜夜は、来週いちばん大きなイベントについて、両方の場合を書く形にする。
   - 1行目では「会議」のようにぼかさず、何の話かを普段の言葉で書く。

7. **仮想通貨の書き方の約束。** 切り口は「なぜ動いたか（2つのソースで確認した理由だけ）」か「初心者がやりがちな失敗」にする。チャートの分析、価格の予想、価格の数字は書かない。
