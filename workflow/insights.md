# 今週の改善方針（10/19〜10/25）

## 今週の改善方針

1. **書く前に、直近7日の投稿テーマを書き出し、同じ現象を扱わない。テーマは週1回まで。** 先週は13本が5種類のテーマに集中した。今週は次の3つを使わない：
   - 値段を決めて予約する注文（発表の時の注文を含む）
   - 連勝のあとに取引の量を増やす
   - 「安い」と思って下げの途中で買う
   - 取引の理由をメモする話も先週使ったので、今週は避ける。
   - 朝の候補（毎日違うものを選ぶ）：1日の中で値動きが大きい時間帯と小さい時間帯、経済ニュースの発表日にカレンダーで何を見るか、取引しない日を先に決める理由、1回の取引の量を最初にどう決めるか、負けを止める値段を入る前に決めておく理由
   - 夜の候補：1日に何回も取引しすぎる、SNSの誰かの意見で入る、負けた直後にすぐ次の取引をする、利益をどこで確定するか決めずに入って結局利益を逃す。最後のテーマは、はじめさん本人の「一番大事なのは利食い」という発信と矛盾しない向きで書く。「早く確定しすぎるのが悪い」という書き方はしない。

2. **専門用語を普段の言葉に言い換える。** 先週も残っていた次の言葉は使わない：指値・指値注文、約定、高値づかみ、直近安値、米雇用統計などの指標の正式名、決算、半導体株、スプレッド、逆指値、含み益。（「ロット」は使ってよい。はじめさん側の指示）
   - 言い換えの例：決算 →「3か月分の成績発表」、指標の正式名 →「アメリカの仕事の数の発表」
   - 金額の例は1投稿に1つだけにする。「〇倍」「〇回分を足すと」のように、読者が掛け算や足し算をしないと分からない書き方はしない。

3. **語尾は言い切る。「そうだ」は将来の見通しにだけ使う。** 事実や仕組みの説明で「〜はず」「〜そうだけど」「〜あるそうだ（伝聞）」は使わない。言い切れないことは書かない。但し書きはかっこ書きで後ろに付け足さず、1行で言い切る。

4. **1行目は24文字以内で「具体的な場面＋困った結果」を入れる。** 「〇〇は△△の影響を受ける」のような説明文から始めない。「〜しがち」のようなぼんやりした結果で終わらせない。書いたら文字数を数える。
   - 本文は5行前後で、流れは「場面 → なぜそうなるか → 円の例1つ → 締め」。
   - 締めは、朝は行動を1行で言い切る。夜は「僕は〜と決めている」。
   - 同じ締めの言い回し（「これを知ってから入るだけで全然違う」など）は週に1回まで。

5. **土曜朝は必ず3市場のまとめにする。** ナスダック・ゴールド・ドル円の3つについて、それぞれ「何があって、どちらに動いたか」を1〜2行ずつ書く。1つの市場だけで終わらせない。価格の数字は書かない。

6. **週末の4本で、同じ市場を主役にするのは2本まで。**
   - 土曜夜と日曜朝は、それぞれ違う市場の「今週なぜ動いたか（出来事 → 金利や見方の変化 → 値動き）」を書く。一般論や仕組みだけの説明にはしない。締めは「何を見れば流れが分かるか」。
   - 「普通の感覚と逆になる理由」の切り口は今週も1本使う。
   - 来週のイベントは日曜夜だけで扱い、「予想より強ければ〜そうだ／弱ければ〜そうだ」と場合分けで書く。
   - 先週の日曜夜に書いた「木曜朝のメタの成績発表」のような日付は、使う前に必ず2つのソースで確かめる。

7. **平日の相場投稿は、ナスダック・ゴールド・ドル円のどれかが大きく動いた日だけにする。それ以外の日は基礎と失敗談を優先する。** 先週は、相場の投稿のエンゲージ率が基礎・失敗談より低かった。相場を書く日はその日に一番大きく動いたものを選び、「なぜ動いたか」を一本の流れで書く。自分がいつ入りたいかは書かない。将来の値動きは断定しない。

8. **毎日9:00と18:00の2本を欠かさない。大きな発表がある日の夜も飛ばさない。** 絵文字は通常のルール（0〜2個）に戻す。絵文字なしの2週間は、自動投稿の表示回数・エンゲージ率とも絵文字ありの週を下回った（ほかの変更も重なっているため、絵文字だけの効果とは言えない）。
