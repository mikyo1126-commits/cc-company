# 今週の改善方針（10/26〜11/1）

## 今週の改善方針

1. **【最優先】数字のルールを守る。書き終えたら、数字（算用数字・漢数字の金額・回数）を数えてから出す。** 先週は夜の5本中4本に金額があり、朝の5本中4本に金額が2つあった。
   - 夜の失敗談：金額・回数・倍率を1つも書かない。1行目も同じ。どれくらい傷が広がったかは「その日の勝ち分が消える」「取り返すつもりが傷が広がる」のように普段の言葉で書く。
   - 朝の基礎：円の金額は1つまで。「普段は〜が〜になる」のように2つの金額を比べる書き方はしない。比べる時は、金額を1つだけ出して「それよりずっと大きくなる」と言葉で書く。
   - 日付や時刻（「木曜の朝3時」など）は使ってよい。

2. **テーマは週1回まで。直近2週間に使ったものは使わない。** 先週、取引の量の決め方を2回使った2本（月朝・水朝）が自動投稿の下位2本になった。今週は次を使わない：
   - 取引の量の決め方、1日中チャートを見て回数が増える、週末をまたいで持つ、早朝は売り買いの値段の差が広がる、発表の瞬間に止める注文が滑る、利益の確定場所を決めずに入る、止める線をずらす、誰かの投稿を真似する、負けを取り返しにいく
   - 前々週の分（予約する注文、連勝のあと、下げの途中で買う、理由をメモする）も使わない。
   - 朝の候補：取引しない日を先に決める、1日の中で動く時間と動かない時間、経済ニュースの発表をカレンダーで先に確認する、口座のお金をすべて使わずに残しておく理由、初めての取引で確かめること
   - 夜の候補：勝った日にやめられずに続ける、損が出ている取引ほど長く持ってしまう、寝る前に慌てて入る、ニュースの見出しだけで入る、休むと決めた日に結局取引する
   - 夜のテーマは、はじめさん本人の「利食いが一番大事」という発信と矛盾しない向きで書く。

3. **1行目は「予想と逆の結果」を、前提知識なしで分かる形で書く。** 先週の上位3本は「〜ほど」「〜のに」「〜はずが」の形だった。ただし「金利が高い通貨は買われる」のような知識がないと意外さが伝わらない1行目は、反応が低かった。読者が日常の感覚で「え、なんで？」と思える逆説にする。24文字以内で、「いつ・何をした時」と「どうなるか」を入れる。

4. **朝の締めは必ず行動を1行で言い切る。** 金額の例や説明で終わらせない（先週は2本が例で終わっていた）。本文は「場面 → なぜそうなるか → 例 → 行動」の流れを1本につなぐ。「けど」で始まる行など、前の行とつながらない文は入れない。

5. **同じ言い回しを繰り返さない。** 先週は「仮に」が朝の5本全部、「正直」が3本、「〜人がいる」で終わる1行目が2本あった。どれも週2回までにする。「正直ここを雑にしてる人は多い」のような中身のない1行は入れない。

6. **週末は先週の形を続ける。そのうえで次の3点を直す。**
   - 土曜朝は、先週と同じくナスダック・ゴールド・ドル円の3つをそれぞれ「何があって、どちらに動いたか」で書く。今週の材料はアメリカの金利の会議と日銀。
   - 土曜夜と日曜朝は、違う市場の「今週なぜ動いたか」を書き、締めは「何を見れば流れが分かるか」にする。来週の会議や発表の名前は出さない（来週のイベントは日曜夜だけで扱う）。
   - 日曜夜は「〜なら〇〇は〜そうだ／〜なら〜そうだ」と両方の場合を書き、最後は文として言い切って終える。「〜かどうか」で止めない。
   - 週末の4本の間で事実が食い違わないようにする（例：「金利は下がるはずが」と「金利を上げたばかり」が同じ週末に並ぶと読者が混乱する）。金利の動きの経緯は2つのソースで確認してから書く。

7. **平日の相場投稿は、木曜（会議の結果が出た日）だけを候補にする。** 木曜の朝3時の結果でナスダック・ゴールド・ドル円のどれかが大きく動いたら、木曜の9:00か18:00のどちらか1本を相場の投稿にする。一番大きく動いたものを選び、「結果 → 見方の変化 → 値動き」で書く。価格の数字、自分がいつ入りたいか、将来の値動きの断定は書かない。はじめさん本人が書いている「PHP」の件は、2つのソースで中身を確認できない限り触れない。「暴落」などの煽る言葉も使わない。

8. **毎日9:00と18:00の2本を時刻どおりに出す。**（先週は全14本が時刻どおりだった。この状態を続ける）
