# 週次レビューからの改善方針（2026-09-28〜10-04 の分析）

## 今週の改善方針（10/05〜10/11）

1. **同じテーマを1週間に2回使わない。** 先週は朝の基礎で「ロット計算」を3回、夜の失敗談で「損切りをずらす」を3回書き、繰り返すほど反応が落ちた。今週はこの2テーマを使わない。朝はたとえば手数料のしくみ、注文の出し方の違い、勝つ時と負ける時の金額のバランス、時間帯ごとの値動きの特徴、経済ニュースの見方から選ぶ（どれも専門用語を使わず普段の言葉で書く）。夜は取引しすぎてしまう、大きな発表をまたいで持ち続ける、負けを取り返そうと取引の量を増やす、利益を早く確定しすぎる、などから選ぶ。毎日違うテーマにする。

2. **朝の基礎投稿は「よくある間違い → 正しい考え方 → 計算や具体例 → 使えるルール1行」の流れにする。** 1〜2行目で「多くの人がやるけど逆」「これが一番危ない」のように、よくある思い込みをはっきり否定する。最後は計算式で終わらせず、読んだ人がそのまま使えるルールを1行で言い切って締める。

3. **具体例の数字は「円の金額」と「回数」だけにする。** pipsや割合（％）の計算は、FXをやったことがない人には通じないので使わない（はじめさん側の指示）。例え話でも、相場の価格や水準を数字で書かない。1文に数字を3つ以上詰め込まない。

4. **夜の失敗談は、その日や翌日の大きなイベントがあればそれに結びつける。** 今週は木曜午前3時にFOMC議事要旨がある。水曜夜は指標やイベントをまたいで持つ失敗など、そのタイミングの読者に関係するテーマを選ぶ。最後は「僕は〜と決めている」と自分のルールで締めて、説教口調にしない。

5. **相場の投稿は、ナスダック・ゴールド・ドル円に大きな動きがあった時だけ書く。** 同じくらいの動きならゴールドを優先する。「なぜ動いたか（材料 → 金利や観測 → 値動き）」をひとつながりで説明する。見通しは「〜そうだ」で書くが、毎回同じ締めの言葉を使わない（先週は「分かれ目になりそうだ」が6件中5件）。「何を見れば判断できるか」を具体的に書く形に変える。

6. **土日の4投稿は、それぞれ違う切り口・違う市場にする。** 土曜朝はナスダック・ゴールド・ドル円の3つをまとめる。土曜夜と日曜朝のファンダメンタルズは、違う市場か違う材料を扱う（同じ指標の結果で書き出さない）。日曜夜は来週のイベントを、何が起きたらどうなるかの場合分けで書く。

7. **語尾を毎回見直す。** 先週「〜っぽい」が2件あった。「っぽい」「かも」「気がする」は使わない。見通しは「〜そうだ」、事実は言い切る。将来の値動きは断定しない。

## 今週試してみること（来週の分析で効果を確かめる）

A. **朝の基礎投稿のうち2本（火・木）だけ、最後のルールの後に読者への短い質問を1行加える。**（例：自分ならどう決めているか、を聞く形）。返信数とエンゲージ率を、質問なしの基礎投稿と比べる。
