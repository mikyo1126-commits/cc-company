# 週次レビューからの改善方針（2026-10-05〜10-11 の分析）

## 今週の改善方針（10/12〜10/18）

1. **テーマは週に1回まで。書く前に、直近7日の投稿と同じ現象を扱っていないか確認する。** 先週は朝5本のうち4本が「勝率と勝ち負けの金額のバランス」になり、「負けを取り返そうと量を増やす」と「週末をまたいで月曜に価格が飛ぶ」もそれぞれ2回使った。今週はこの3つを使わない。
   - 朝の候補（毎日違うものを選ぶ）：注文の出し方の違い（今すぐ買う／値段を決めて予約する）、1日の中で値動きが大きい時間帯と小さい時間帯、経済ニュースの発表日の見方、取引しない日を決める理由、取引の記録のつけ方
   - 夜の候補：利益を早く確定しすぎる、1日に何回も取引しすぎる、SNSの誰かの意見で入る、「下がったから安い」と飛びつく、連勝のあとに気が緩む

2. **読者に計算をさせない。** 先週は14本中5本でpipsや％を使った。今週は1本もpips・％・勝率・計算式を使わない。具体例は1投稿につき1つまで、円の金額か回数で書く。
   - 次の言葉は使わず、普段の言葉に言い換える：スプレッド、逆指値、ロット、含み益、リスクリワード、初動、退場、指標の正式名（ISM、FOMC議事要旨など）
   - 言い換えの例：ロット → 「1回の取引の量」、FOMC議事要旨 → 「アメリカの金利を決める会議の記録」

3. **1行目は24文字以内を必ず守る。** 書いたら文字数を数え、超えたら削る。先週は6本が超えていた。1行目で伝えることは1つだけにして、「いつ・何をした時」と「どうなるか」を入れる。「〜と思ってるなら逆」「〜なのに〜」の型は週に2回までにして、書き出しを毎回変える。

4. **本文は5行前後にして、最後の1行は必ず使えるルールで締める。** 朝は「入る前に〜する」「〜の時は取引しない」のように行動を1行で言い切る。夜は「僕は〜と決めている」で締める。「〜な人は多い」で終わらせない。

5. **土曜朝は必ず「今週のまとめ」にする。** ナスダック・ゴールド・ドル円の3つについて、それぞれ「何があって、どちらに動いたか」を1〜2行で書く。価格の数字は書かない。

6. **土曜夜・日曜朝・日曜夜の締めで、同じイベントを指さない。** 先週は3本が「水曜の物価の発表」で終わっていた。
   - 土曜夜と日曜朝：違う市場の「なぜ動いたか（出来事 → 金利や見方の変化 → 値動き）」を書き、締めは「何を見れば流れが分かるか」にする。
   - 来週のイベントは日曜夜だけで扱い、「予想より強ければ〜そうだ／弱ければ〜そうだ」と場合分けで書く。
   - 物価が上がると金が売られる、のように「普通の感覚と逆になる理由」を説明する切り口は、先週反応が良かった（2本だけなので傾向として扱う）。今週も1本は使う。

7. **平日の相場投稿は、ナスダック・ゴールド・ドル円が大きく動いた日だけ書く。** 3つの優先順位は決めず、その日に一番大きく動いたものを選ぶ。「なぜ動いたか」を一本の流れで書き、見通しは「〜そうだ」で書く。将来の値動きは断定しない。自分がいつ入りたいかは書かない。

8. **今週も絵文字は使わない。** 先週の比較がまだできていないため。
